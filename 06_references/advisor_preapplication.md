# 주제별 연구계획 [1순위]

## 1. 핵심논문 정보 및 요약

- **논문명**: A systematic approach for identifying technology opportunities: Keyword-based morphology analysis
- **저자 및 출판정보**: Yoon, B., & Park, Y. (2005). *Technological Forecasting and Social Change*, 72(2), 145–160.

### 핵심논문 요약 및 형태분석 적용 사례 (Yoon & Park, 2005)

본 논문은 특허정보에서 핵심 기술 차원(Dimensions)과 그 하위 수준(Shapes)을 도출하여 형태분석 매트릭스를 구성하고, 이를 통해 미개척된 기술조합 기회를 정량적으로 탐색하는 체계적인 기틀을 제공했다.

※ 형태분석의 실제 사례 (LCD 제조기술 적용 예): LCD 모드(TN, MVA, IPS)를 개발하기 위해 7가지 형태 차원(Alignment, Light mode, Domain 등)과 각각의 세부 형태들을 구조화하고 조합 경로를 매핑한 사례다.

### 기존 연구의 한계점

- 키워드나 단순 사전에 의존해 기술 요소를 추출할 경우, 서로 상충하거나 양립 불가능하여 기술적으로 실현할 수 없는 '모순(Contradiction)' 조합과 실제 개척 가치가 높은 미래 '기회(Opportunity)' 조합이 구분되지 않는다.
- 키워드 분류와 Dimension/Shape 설정에 전문가의 판단이 많이 개입되어, 분석 결과의 일관성과 재현성이 떨어질 수 있다.

### 본 연구의 차별성 및 기술 시나리오 사분면 (2×2 Matrix)

본 연구는 특허를 Problem–Solution–Effect(PSE) 기반 지식그래프로 변환하고 벡터 임베딩을 적용한다. 이를 기초로 앞으로 일어날 법한지(결합 가능성, P)와 지금 이미 같이 쓰이는지(현재 점유도, occ)를 두 축으로 설정하여 기술 시나리오를 4분면으로 구분·도출한다.

| 구분 | 축 정의 | 세부 정의 및 특징 |
|---|---|---|
| 기존 기술 (Established) | 높은 P / 높은 occ | 이미 유용하게 함께 쓰이고, 모델 예측상 앞으로도 결합 확률이 높은 성숙한 조합 |
| 미래 기회 (Opportunity) | 높은 P / 낮은 occ | 아직 함께 쓰이지 않으나 기술적 양립성이 높아 결합 가치가 큰 혁신 기회 조합 |
| 모순 (Contradiction) | 낮은 P / 낮은 occ | 쓰이지 않으며 정합성이 낮아 결합이 불합리한 비양립 조합 |
| 검토 (Review) | 낮은 P / 높은 occ | 특허상 이미 함께 쓰이나 모델이 결합 가능성을 낮게 봐 예외 원인 검토가 필요한 조합 |

# 주제별 연구계획 [2순위]

## 핵심논문 정보 및 요약

- **논문명**: Knowledge graph-assisted design-by-analogy: promoting product innovation through structured analogical knowledge retrieval
- **저자 및 출판정보**: Jing, L., Huang, M., Li, Q., Dou, Y., Feng, D., & Jiang, S. (2025). *AI EDAM*, 39, e20, 1–32.

### 핵심논문 요약 (Jing et al., 2025)

이종 분야 설계 지식을 체계적으로 연계하기 위해 기능-효과-구조(I-FES) 온톨로지 기반 지식그래프(DbAKG)를 구축하고, 도메인 거리와 시맨틱 유사도를 결합한 아날로지 값(AV) 모델로 참신성과 실현 타당성을 균형 있게 평가하는 정량적 검색·추천 메커니즘을 제안했다. 다만 기계 구조 중심의 '추상적 개념 설계안' 도출이라는 정성적 아이디어 기획 단계에 머문다는 한계가 있다.

### 본 연구의 차별성

기존 '개념적 지식 매핑' 한계를 넘어, 화학 공장·발전소 배관의 실시간 이상 탐지를 위한 에지 AI 모델의 실용적 구현을 제시한다. 이종 특허 지식을 연산 제약식으로 컴파일하여 실제 기동·성능 검증이 가능한 AI 모델 코드를 생성·입증하는 실행형 프레임워크.

### 참조 소스별 딜레마

- **동일 분야 산업 특허**: 구현 힌트는 풍부하나 상업화 시 특허 침해 소송·법적 리스크에 상시 노출.
- **유명 학술 AI 논문(SOTA)**: 신빙성은 높으나 자원 제약 없는 고사양 인프라 중심이라 자원 제약 장비 적용이 어려움.
- **제안 대안(이종 분야 특허)**: 전통 비-AI 공학 도메인 특허는 분류·권리 범위가 달라 침해 리스크를 차단하면서, 극한 자원 제약에서 기계를 안정 제어한 강건한 물리·수학 최적화 로직을 보유.

### 물리-딥러닝 아키텍처 제약조건 매핑 매트릭스

| 원천 물리 도메인 (전통 유체 제어 특허) | 대상 AI 도메인 (에지 딥러닝 최적화) |
|---|---|
| 배관 내부 물리적 유체 압력 (P) | 실시간 연산 시 점유 중인 GPU VRAM |
| 배관 파손 임계점 (최대 허용 압력) | VRAM 물리적 상한선 (예: 4GB) |
| 메인 유체 밸브 긴급 차단 (Flow Stop) | 가중치 기반 동적 가지치기 (Dynamic Weight Pruning) |
| 보조 바이패스 밸브 동적 개방 | 피처맵 연산을 일시 스킵/우회하는 동적 스킵 게이트 |
| 물리적 유체 흐름 변화율 제어 수식 | 손실 함수 내 Gradient 변동 동적 정규화 제약식 |

### 핵심 가치: LLM Agent 기반 코드 자동 생성 — 5대 과제

1. **검색/Retrieval**: VRAM 4GB 하한선을 돌파하는 데 수치적으로 가장 잘 매핑되는 이종 산업군 특허를 식별하는 구조적 검색식·필터링 메커니즘 수립.
2. **추상화/Abstraction**: 도메인 종속 용어(파이프, 밸브)를 배제하고 수치 변동 한계치·동적 흐름 우회 법칙을 도메인 독립 수리 형태의 '제어 로직 추상화 템플릿'으로 압축.
3. **코드화 전환/Translation**: 추상화된 물리 룰을 LLM Agent가 PyTorch로 변환하도록 프롬프트 규칙·제약조건 가이드 등 기계 해독 가능 지식으로 매핑.
4. **검증 매트릭/Metrics**: F1-score뿐 아니라 VRAM 점유량·레이턴시 개선율·연산 효율 등 하드웨어 제약 충족도를 통합 측정하는 다차원 평가 매트릭 설계.
5. **케이스 검증/Case Study**: 화학 공정 배관 다변량 시계열 이상 탐지 환경에서 하드웨어 제약 만족과 정확도 강건성을 수치로 증명.

### Agent 기반 코드 자동 생성 3단계 대조군 실험

- **[실험 1] Base Agent Flow**: 기본 요구사항만 프롬프트로 전달해 코드 자동 작성 후 평가.
- **[실험 2] SOTA Paper Flow**: 성능 중심 AI SOTA 논문 수식·공개 GitHub 소스를 참조로 제공해 코드 생성·평가.
- **[실험 3] Cross-Domain Patent Flow (제안)**: 이종 산업 전통 기계 특허(바이패스 제어) 물리 제약을 Agent 가이드로 탑재, OOM을 차단하는 Pruning·Skip Gate 코드를 자동 변환해 성능·자원 제약 정량 검증.
