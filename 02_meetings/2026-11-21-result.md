# 2026-11-21 미팅 결과 — 사회적 수요 식별 방법론과 기술기회 발굴의 차별성

**주제:** 사회적 수요 식별 방법론 구체화 및 특허 기반 기술기회 발굴 연구의 차별성

## 1. 사회적 수요의 정량적 식별 및 분석 범위

현재 LSMS-ISA 데이터를 활용하여 소농의 경제적 취약성, 가족 노동 부담, 농업 생산성 등을 분석하고 있으며, 사회적 수요가 집중된 집단과 부담의 특성을 정량적으로 파악하고 있음.

정량적 수요 분석은 **현재 수준의 기술통계 중심으로 유지**하고, 추가적인 심화 분석의 필요성은 크지 않은 것으로 논의됨.

본 연구의 핵심은 정량분석 자체보다 **식별된 사회적 수요를 실제 농업 작업의 문제와 기능 요구사항으로 구체화하고, 다양한 기술기회로 연결하는 과정**에 있음.

## 2. 농업 Workflow 분석 및 기능·기술 전개

### 2.1. 농업 작업 프로세스 구체화

현재 정량분석만으로는 실제 농업 현장에서 어떤 작업이 어렵고 노동 부담이 큰지 파악하기 어려우므로, 이를 기능 요구사항으로 직접 연결하는 데 한계가 있음.

따라서 FAO 및 관련 문헌을 활용하여 실제 농업 현장의 Workflow를 구체화할 필요가 있음.

- 농업 작업의 종류와 수행 순서
- 작업별 어려움, 노동 부담 및 소요 시간
- 작업 수행 빈도(매일, 계절별 등)
- 가족 구성원 간 작업 분담 및 역할
- 작업에 필요한 노동력과 자원

이를 통해 사회적 수요를 구체적인 작업상의 문제와 미충족 요구사항으로 정의해야 함.

### 2.2. 핵심 작업 선정 및 기능·기술 전개

농업 Workflow와 작업별 부담을 분석한 후, 사회적 수요가 집중된 핵심 작업을 선정하고 이를 기능 요구사항과 기술적 대안으로 전개함.

**정량적 수요 식별 → Workflow 분석 → 핵심 작업 선정 → 기능 요구사항 도출 → 기술적 대안 탐색**

정량분석은 수요의 대상과 특성을 파악하는 역할을 수행하며, 실제 기술적 요구사항의 구체화는 Workflow 분석과 기능 도출 단계에 중점을 둠.

### 2.3. 단계 간 정합성 및 반복적 검토

정량적 수요 분석에서 식별한 문제와 실제 Workflow에서 확인되는 작업별 부담이 일치하지 않을 수 있음.

이 경우 초기 수요 정의를 고정하지 않고, **정량적 수요 식별과 Workflow 분석 간 반복적 검토(Iteration)**를 통해 수요의 정의나 분석 범위를 조정할 수 있음.

이는 정량분석을 심화하기보다 실제 작업 수준의 근거를 바탕으로 수요를 보완하는 과정임.

## 3. 논문의 핵심 학술적 기여 및 QFD와의 차별성

본 연구의 핵심 기여는 **수요자의 니즈가 명확하지 않은 산업에서 사회적 수요를 체계적으로 도출하고, 이를 다양한 기술기회로 연결하는 방법론**을 제시하는 데 있음.

일반적인 B2C 제품개발은 설문조사, 시장조사 등을 통해 고객 니즈를 체계적으로 파악할 수 있으나, 농업과 같이 수요가 명확하게 표현되거나 수집되지 않는 영역에서는 이러한 접근에 한계가 있음.

따라서 다음 두 가지 측면에서 차별성을 확보해야 함.

**① 명확하지 않은 수요의 체계적 식별**

사회경제적 데이터와 실제 작업 프로세스 및 부담을 결합하여 기존에 명확히 정의되지 않았던 수요를 구체화함.

**② 다양하고 구체적인 기술적 대안 발굴**

식별된 수요를 기능 요구사항으로 전환하고, 기존 QFD(Quality Function Deployment) 방식과 비교하여 더욱 구체적이고 다양한 기술적 해결 경로를 도출할 수 있어야 함.

단순한 수요 식별이나 기능 연결을 넘어, **기존 방법론에서 발견하기 어려웠던 기술적 대안을 발굴하는 것**이 중요한 학술적 기여임.

## 4. 기존 NPD 연구와의 차별성

특정 제품을 중심으로 요구사항과 기술을 전개하면 기존 NPD(New Product Development) 프로세스와 유사해질 수 있음.

따라서 제품을 중심 단위로 설정하지 않고, **사회적 수요에서 기능 요구사항을 도출하여 다양한 기술적 해결 경로를 탐색하는 것**에 초점을 두어야 함.

**Needs → Functions → Technologies**

하나의 수요가 복수의 기능과 기술적 대안으로 확장될 수 있어야 하며, 특정 제품이나 사전에 정해진 해결책에 종속되지 않아야 함.

이를 통해 제품개발이 아닌 기술기회 발굴(TOD) 방법론으로서의 차별성을 유지함.

## 5. 주요 논의 사항 요약

| 구분 | 주요 논의 내용 |
|---|---|
| 정량적 수요 분석 | 현재 기술통계 중심 분석 유지, 심화 분석 최소화 |
| Workflow 분석 | FAO 등 문헌을 통해 작업별 부담, 시간, 빈도, 가족 내 역할 구체화 |
| 기능·기술 전개 | 핵심 작업 선정 후 기능 요구사항 및 다양한 기술적 대안 도출 |
| 단계 간 정합성 | 정량분석과 Workflow 결과가 불일치하면 반복적으로 검토·조정 |
| 학술적 기여 ① | 니즈가 명확하지 않은 산업에서 수요를 체계적으로 식별 |
| 학술적 기여 ② | 기존 QFD 대비 구체적이고 다양한 기술적 대안 발굴 |
| NPD와의 차별성 | 제품 중심이 아닌 Needs–Functions–Technologies 전개 |
