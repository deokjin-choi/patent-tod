# 특허 기반 기술기회 발굴 (Technology Opportunity Discovery)

특허 데이터를 분석해 **아직 시도되지 않았지만 앞으로 함께 쓰일 가능성이 높은 기술 조합**, 즉 기술기회를 찾아내는 연구 프로젝트입니다.

## 프로젝트 소개

특허에는 기업과 연구자들이 어떤 기술을 어떻게 조합해 왔는지가 기록되어 있습니다. 이 프로젝트는 특허에서 핵심 기술 요소를 뽑아, 이 요소들이 서로 어떻게 조합될 수 있는지를 하나의 공간으로 정리합니다. 그리고 그 안에서 다음 두 가지를 구분합니다.

- **이미 함께 쓰이고 있는 조합**: 시장에서 자리 잡은 기존 기술
- **아직 드물지만 함께 쓰일 가능성이 높은 조합**: 새로 시도해 볼 만한 기술기회

기술적으로 함께 쓰기 어려운 조합은 따로 걸러내어, 비어 있는 자리를 모두 기회로 오해하지 않도록 합니다. 또한 과거 데이터로 찾은 기회가 실제로 이후의 특허 출원으로 이어졌는지 확인해, 이 방법이 실제로 쓸모 있는지 검증합니다.

현재는 Edge AI 분야 특허를 대상으로 방법을 시험하고 있습니다.

## 저장소의 목적

이 저장소는 지도교수와의 공동연구를 체계적으로 진행하고, 그 결과를 논문으로 완성하기 위한 작업 공간입니다. 연구 설계, 선행연구 조사, 데이터 분석, 월례 미팅 기록, 논문 작성까지 연구의 모든 과정을 이곳에서 관리합니다.

## 폴더 구조

```text
.
├── README.md            # 저장소 소개 (본 문서)
├── 01_paper/            # 논문 작성
│   ├── design/          #   연구 설계 (연구 개념, 연구 방법, 평가 기준)
│   ├── draft/           #   논문 원고
│   └── figures/         #   논문에 넣을 그림
├── 02_meetings/         # 지도교수 월례 미팅 기록
├── 03_literature/       # 선행연구 조사와 참고문헌
├── 04_src/              # 분석 코드
│   ├── scenario_pipeline/
│   ├── em_mcmc/
│   └── pilot_federated_learning/
├── 05_data/             # 특허 원자료 (Git에 올리지 않음)
└── 06_references/       # 참고용 자료
```

## 폴더별 역할

| 폴더 | 역할 |
|---|---|
| `01_paper/` | 논문과 관련된 모든 글을 모읍니다. `design/`에는 연구 설계(연구 개념, 연구 방법, 평가 기준)를, `draft/`에는 논문 원고를, `figures/`에는 논문에 넣을 그림을 둡니다. 설계가 충분히 정리되면 원고로 옮겨 씁니다. |
| `02_meetings/` | 지도교수와 매달 한 번 진행하는 미팅을 기록합니다. 한 달에 파일 하나(예: `2026-10.md`)를 만들고, `_template.md` 양식을 복사해 작성합니다. |
| `03_literature/` | 선행연구를 조사하고 정리합니다. 참고문헌 목록(`bib/`), 선행연구 정리 문서, 문헌 수집에 쓴 스크립트가 들어 있습니다. |
| `04_src/` | 분석 코드를 둡니다. 데이터 전처리부터 기술 그룹 도출, 기술 조합 생성, 검증까지의 실험 코드이며, 현재 `scenario_pipeline`, `em_mcmc`, `pilot_federated_learning` 세 가지 실험이 있습니다. |
| `05_data/` | 특허 원자료와 분석 중간 결과를 둡니다. 용량이 커서 Git에는 올리지 않습니다. |
| `06_references/` | 직접 작업하는 문서는 아니지만 참고용으로 보관하는 자료입니다. 연구계획서 정리본, 분석 결과 예시 등이 있습니다. |

## 작업 흐름

1. **연구 설계**: `01_paper/design/`에서 연구 질문, 방법, 검증 기준을 정합니다.
2. **분석 수행**: `04_src/`에서 분석을 실행하고 결과 그림과 표를 정리합니다.
3. **월례 미팅**: 매달 `02_meetings/`에 진행 상황과 결정 사항을 기록하고, 확정된 내용은 연구 설계에 반영합니다.
4. **논문 작성**: 설계가 안정되면 `01_paper/draft/`에서 원고를 씁니다.
